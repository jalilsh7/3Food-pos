# قرارداد ادامه کار هوش مصنوعی — 3Food POS V2

1. پیش از هر کار، آخرین commit شاخه فعال را از GitHub بخوان؛ از ZIP یا snapshot قدیمی به‌عنوان مبنا استفاده نکن.
2. محدوده این سند فقط V2 است. کد V2 در ریشه `src/` و `php-backend/` قرار دارد؛ V3 در `v3/` و `database/v3/` مستقل است.
3. برای توسعه V2 از شاخه فعال V2 استفاده کن؛ `main` فعلی مبنای V2 نیست. تغییرات ساختاری را در شاخه کاری جدا انجام بده و با PR قابل بررسی ارائه کن.
4. نیاز قطعی فروشگاه یک صندوق است؛ قابلیت چندصندوقی را اضافه نکن مگر مالک صریحاً درخواست کند.
5. نقش‌های manager، cashier و kitchen و کنترل مجوز در PHP حفظ شوند.
6. MySQL مرجع حقیقت داده عملیاتی است. منطق مالی، سفارش، تخفیف، مالیات، موجودی و وفاداری نباید فقط به UI متکی باشد.
7. idempotency، تراکنش‌های اتمیک، قفل موجودی، audit و محدودیت‌های restore را تضعیف نکن.
8. اطلاعات SMS و سایر secretها فقط در config خصوصی سرور باشند. خطای SMS نباید ثبت سفارش را ناموفق کند.
9. درایور کارتخوان واقعی را بدون مستندات PSP و آزمون دستگاه ادعا نکن.
10. پیش از حذف یا جابه‌جایی سورس، importها، مسیرهای build، workflowها و تست‌ها را بررسی کن.
11. پس از تغییرات، typecheck، تست، lint و build:cpanel را اجرا کن؛ نتیجه‌ای را که اجرا نشده موفق گزارش نکن.
12. CI، staging، production و تأیید مالک چهار مرحله مجزا هستند. به هاست یا دیتابیس زنده دست نزن.
13. دفترهای تاریخی در `docs/v2/history/` مرجع زمینه‌اند؛ برای وضعیت جاری از STATUS و OPERATIONS استفاده کن.
